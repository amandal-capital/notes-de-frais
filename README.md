# Notes de frais — AMANDAL / AMANRÉ

Application interne de saisie, d'impression et de suivi des notes de frais.

- Numérotation continue par société : NDF-AMD-AAAA-0001, NDF-AMR-AAAA-0001
- Comptes : collaborateur, caisse, RAF (consultation + export), administrateur
- PDF au format du modèle AMANDAL (A4 paysage), justificatifs en option
- Export Excel de toutes les notes

Version test : les données sont enregistrées dans le navigateur de chaque utilisateur.
